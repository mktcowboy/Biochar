# Verra VM0044 Project Cycle and MRV

**Parent hub:** [[Verra VM0044]]  
**Rules:** [[Verra VM0044 Methodology and Eligibility]]  
**Math:** [[Verra VM0044 Permanence and Quantification]]  
**Generic MRV:** [[MRV Stack]]  
**Compare:** [[Puro Project Cycle and MRV]] · [[Isometric Project Cycle and MRV]]

This chapter walks **listing → validation → monitoring → verification → VCU issuance**, including public Verra fees and CCP labeling. Methodology monitoring parameters cite [VM0044 v1.1 PDF](https://verra.org/wp-content/uploads/2023/07/VM0044-Methodology-for-Biochar-Utilization-in-Soil-and-Non-Soil-Applications-v1.1.pdf); program fees cite [Verra Program Fee Schedule v1.1 (27 Jul 2026)](https://verra.org/wp-content/uploads/2024/10/Verra-Program-Fee-Schedule-v1.0.pdf).

---

## End-to-end cycle (one page)

```
Verra Registry account
        ↓
Pipeline listing (VM0044)
        ↓
Project Description + Monitoring Plan
        ↓
Validation (accredited VVB)
        ↓
Registration review
        ↓
Produce biochar → characterize → apply within 1 year
        ↓
Monitoring / reporting period
        ↓
Verification (VVB) + CCP checklist if seeking CCP labels
        ↓
Issuance request → Removals VCUs (± CCP label)
        ↓
Transfer / retirement
```

**Critical ops rules:** waste demonstration at validation; greenfield facility; utilization within **one year**; high-tech four-gate if claiming high-tech / non-soil path ([[Verra VM0044 Methodology and Eligibility]]).

## Step detail

| Step | What happens | Notes |
|---|---|---|
| 1. Account | Open Verra Registry account | Fee schedule account fees |
| 2. Pipeline listing | List project intending VM0044 | USD 1,500 listing fee |
| 3. Documentation | PD, monitoring plan, additionality (incl. **VT0008 investment analysis** under v1.2), App. 2 waste evidence | Heaviest prep |
| 4. Validation | Independent VVB validates design against VCS + VM0044 | VVB commercial fee separate |
| 5. Registration | Verra registration review | USD 3,750 |
| 6. Operations | Produce, lab (high-tech), apply, CoC | ≤1 year to use |
| 7. Verification | VVB verifies monitored removals | USD 5,000 Verra review (+ VVB) |
| 8. Issuance | Removals VCUs; optional CCP label | USD 0.23 / claimed tCO₂e levy |
| 9. Transfer / retire | Market transactions | USD 0.02 / VCU each |

v1.1 grace path for completing registration under v1.1 closed after listing-before-27-Jun-2025 / validation-by-27-Dec-2025 ([methodology page](https://verra.org/methodologies/vm0044-biochar-utilization-in-soil-and-non-soil-applications-v1-2/)).

## Monitoring themes (methodology)

Aligned to v1.1 §9 / quantification sections (confirm live v1.2 §9):

| Domain | Monitor / evidence |
|---|---|
| Feedstock | Waste status (App. 2), category, sustainability criteria, origin (no import), transport distances |
| Production | High- vs low-tech classification; temperature class for Table 3; dry mass \(M\); organic C \(FC\) (lab high-tech); energy / PE terms |
| Biochar quality | IBI/EBC (or national) contaminant compliance; soil **H:Corg ≤ 0.7** |
| Application | Soil land type / mixing rules **or** non-soil longevity evidence; utilization ≤ 1 year from production |
| Leakage / transport | Tool 12 freight emissions; activity-shifting themes |
| Records | Retrievable ≥ **two years** after end of project crediting period (v1.1) |

Calibration of mass instruments: practitioner materials often cite ≤ 3-year cadence — **confirm in PDF §9** rather than treating secondary checklists as authoritative.

## Additionality package under v1.2

1. **Regulatory surplus** (VCS Standard / Methodology Requirements)  
2. Positive-list / activity-method compliance (v1.1 baseline approach)  
3. **Investment analysis (step 3)** per **VT0008** — added in v1.2 for ICVCM alignment ([revision announcement](https://verra.org/verra-publishes-minor-revision-to-biochar-methodology/))

v2.0 consultation would replace the standardized positive list with a **project method** ([consultation](https://verra.org/consultation-major-revision-to-biochar-methodology-vm0044/)) — monitor if designing multi-year pipelines.

## CCP labeling workflow

| Requirement | Source |
|---|---|
| Methodology must be CCP-approved | VM0044 **v1.2** approved 24 Jul 2025 ([ICVCM M43](https://icvcm.org/wp-content/uploads/2025/08/M43_VCS_VM0044_v1.2_2025.pdf)) |
| Attach **CCP Eligibility Verification Report Checklist** as verification-report appendix | [methodology page](https://verra.org/methodologies/vm0044-biochar-utilization-in-soil-and-non-soil-applications-v1-2/) |
| Multi-methodology projects | Only VCUs from **solely** CCP-approved methodologies eligible for CCP labels | same |
| Digital request form | Verra Project Hub CCP Label Request Form lists VM0044 v1.2 | [program notice](https://verra.org/program-notice/verra-launches-digital-ccp-label-request-form/) |
| Guidance | [ICVCM CCP Label Guidance PDF](https://verra.org/wp-content/uploads/2024/12/CCP-Label-Guidance-Document-v1.1-Final.pdf) | Verra |

Requantification procedure exists for updating methodology versions / reconciling past issuances and then requesting CCP labels ([Verra CCP guidance update](https://verra.org/verra-releases-updated-icvcm-ccp-label-guidance/)) — fee USD **10,000** per requantification review (fee schedule).

## Public Verra fees (VCS portion)

From [Verra Program Fee Schedule](https://verra.org/wp-content/uploads/2024/10/Verra-Program-Fee-Schedule-v1.0.pdf) (document **v1.1**, issued **27 Jul 2026**) and [fee update announcement](https://verra.org/verra-releases-updated-fee-schedule/):

| Fee | USD |
|---|---|
| Account opening | 750 |
| Annual account maintenance | 750 |
| Pipeline listing | 1,500 / request |
| Registration review | 3,750 / request |
| Verification review | 5,000 (2,500 + 2,500 issuance prepayment credit) |
| VCU issuance levy | **0.23** / claimed tCO₂e (net of buffer) |
| Requantification review | 10,000 / request |
| Transfer / retirement / cancellation | 0.02 / VCU |
| Mixed reduction/removal label (when applicable) | 0.07 / VCU |
| Article 6 label | 0.05 / VCU |

**Not included:** VVB validation/verification commercial fees (often the largest line item). Compare Puro’s fee narrative in [[Puro Pricing and CORC Indexes]] / [[Puro Project Cycle and MRV]].

## Common failure modes (ops)

1. **Cannot prove waste** baseline (App. 2)  
2. Facility is **not greenfield** under v1.x  
3. High-tech claimed but missing heat-recovery / emissions-control evidence  
4. Soil biochar **H:Corg > 0.7**  
5. Stockpile / delayed application **> 1 year**  
6. Non-soil path without high-tech + longevity evidence  
7. v1.2 **investment analysis** missing  
8. Seeking CCP labels without checklist appendix  

Projects / market: [[Verra Biochar Projects and Market]].

## US producer path (checklist style)

1. Confirm kiln is **new** (or wait for v2.0 / choose other registry)  
2. Map feedstock to Table 1 + App. 2 evidence plan  
3. Decide high-tech vs low-tech early (drives lab budget and non-soil eligibility)  
4. Build VT0008 investment analysis alongside PD  
5. Select VVB experienced with engineered CDR / waste scope 13  
6. Instrument mass, temperature, energy; contract ISO-capable labs  
7. Design application CoC (farm GIS / mixing / concrete batch tickets)  
8. If CCP matters to buyer: bake checklist into verification SOW  

Prairie / NRCS adjacency is **policy**, not VCS MRV: [[NRCS CPS 336 and US Ag]] · [[Policy Hub]].
