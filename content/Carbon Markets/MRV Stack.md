# MRV Stack

## What is measured

| Domain | Typical measurements | Lab vs field |
|---|---|---|
| **Feedstock** | Waste/residue status, sustainability, counterfactual fate, transport, cultivation emissions | Documentary + activity data |
| **Pyrolysis** | Temperature, residence time, O₂ exclusion, mass balance, energy use, flue-gas CH₄/N₂O/CO | Continuous sensors and/or periodic stack tests |
| **Biochar characterization** | C_org, H/C_org, O/C_org, ash, moisture, metals, PAHs, PCDD/F, PCBs; optional Ro, HyPy | **Accredited lab** (ISO 17025) |
| **Application / storage** | Dry mass delivered & applied; GPS; incorporation; matrix mix ratios; custody | Field / logistics evidence |
| **Permanence** | Modeled F_durable / GPC–SPC from lab properties ± soil T | Lab proxies + models |

**Why not field SOC stock change?** Distinguishing biochar-C from native SOC at scale is difficult; standards credit **characterized biochar applied to an eligible sink**, discounted by permanence models—not measured ΔSOC.

## Typical high-integrity characterization package

1. Proximate/ultimate: moisture, ash, VM, C/H/N/O/S
2. C_org (total C − inorganic C)
3. Molar H/C_org and O/C_org
4. Contaminants: Pb, Cd, Cu, Ni, Hg, Zn, Cr, As; PAHs; dioxins/furans; PCBs
5. Agronomic: pH, EC/salts, liming, nutrients
6. Advanced (program-dependent): Ro, BC_HyPy, Rock-Eval

Methods often cited: ASTM D5373 / D1762 / D4373; ISO 16948, 18134, 10390, 17025; ISO 7404-5 for Ro.

## Common issuance pattern

1. Produce & characterize batch
2. Deduct LCA emissions (CSI: retire offsets from emission portfolio)
3. Prove eligible end use with custody trail
4. Apply permanence factor → issue credits **ex post**
5. Maintain records (often ≥5 years); monitor reversal risks
