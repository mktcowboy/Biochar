# Puro Project Cycle and MRV

Parent: [[Puro CORC200+]] · Method detail: [[Puro Biochar Methodology Edition 2025]]

## Certification journey (7 steps)

From [Fees / certify pages](https://puro.earth/certified-carbon-credits/fees/):

1. **Initial Qualification** (questionnaire)
2. **Platform Agreement** + KYC → MyPuro Account Holder (**€1,400**/yr)
3. **Facility Registration** (unique registry ID)
4. **Audit Package** preparation (docs, LCA, Monitoring Plan, additionality questionnaire)
5. **Preliminary Assessment** (optional) → Future Facility listing
6. **Facility Audit** (Puro-allocated VVB; typically on-site first audit)
7. **Output Audits** (≥ annually) → **CORC issuance** → transfer / **retirement**

Point of CORC creation = first **durable eligible use** (not factory gate alone).

## Crediting

- Edition 2025 crediting period: **10 years**, renewable **twice** after new Facility Audit against latest rules
- Capacity expansion of similar reactors possible without resetting period (rules 3.1.6–3.1.8)
- Output frequency scales with volume (General Rules 4.4 table on fees page: from 1×/yr below ~10k CORCs up to 12×/yr above 60k)

## Lab & sampling

| Regime | When | Minimum lab frequency (permanence + C) |
|---|---|---|
| **A** | Continuous uniform carbonization monitoring (1-min T & residence; ±10% stability) | **≥2× per year** per biochar type |
| **B** | No continuous uniform proof | **≥4× per year** per biochar type |

Required analytics: dry mass (impurity-corrected), \(C_{\mathrm{org}}=C_{\mathrm{tot}}-C_{\mathrm{inorg}}\), H → **H/C_org**. Methods listed in methodology §6.1 (ISO 16948, ASTM D5373, DIN carbonate methods, etc.). Auditor may request on-site resample.

## Chain of custody / end-use evidence

- Biomass: source list + batch records + BSC sustainability evidence
- Product: batch IDs, weigh tickets, moisture
- Use: proof matching Table 3.2 (application records, contracts, geotags/GIS as applicable, cascading-fate evidence)
- Intermediaries: agreements preventing diversion / double claiming
- Retail R3: last-intermediary contracts + RDF

## Emissions MRV highlights

- Combustion systems ≥**95%** normal operating time
- Residual **CH₄** and **N₂O** rules for carbonization
- Stockpile CH₄ unless negligible criteria met
- Fossil C in plastics / paints / **sewage sludge** counted as project emissions (assumed fully re-emitted)
- Full LCA: operational + embodied; co-product allocation; leakage assessment

## Auditors (VVBs)

- Must be **Puro-approved** (application + methodology training)
- **Puro allocates** VVB (geography, expertise, availability, rotation, fees)—suppliers do not freely shop
- Conflict-of-interest checks required
- Source: [Validation & Verification Requirements v1.3](https://7518557.fs1.hubspotusercontent-na1.net/hubfs/7518557/Supplier%20Documents/Validation%20and%20Verification%20Requirements%20v1.3.pdf)
